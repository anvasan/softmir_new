# Скилл «На чем мы остановились?»

## Обзор

Этот скилл помогает быстро войти в контекст при начале новой сессии. Он собирает данные из предыдущих разговоров, артефактов и Knowledge Items и формирует структурированную сводку о текущем состоянии проекта.

## Триггер активации

Скилл активируется при использовании одной из следующих фраз (или их вариаций):
- **На чем мы остановились?**
- **Статус проекта**
- **Что уже сделано?**
- **Контекст**
- **Продолжим**
- **Напомни, что мы делали**
- **Где мы?**

---

## Алгоритм работы

### Шаг 1: Сбор данных из истории разговоров

1. Прочитай **summaries последних 5–10 разговоров** (они уже доступны в начале каждого разговора).
2. Определи **тематические кластеры** — какие направления работы велись (например: «SEO-оптимизация», «Перевод категорий», «Монетизация»).

### Шаг 2: Анализ артефактов последних разговоров

1. Для **3 последних разговоров** проверь наличие артефактов:
   - Используй `list_dir` на `<appDataDir>/brain/<conversation-id>/` для каждого разговора.
   - Прочитай `task.md` — найди незавершённые задачи (строки с `[ ]` и `[/]`).
   - Прочитай `implementation_plan.md` — найди текущие планы.
   - Прочитай `walkthrough.md` — найди результаты выполненной работы.
2. Собери все **незавершённые задачи** из найденных `task.md`.

### Шаг 3: Проверка Knowledge Items

1. Просмотри **KI summaries** (доступны автоматически).
2. Выдели KI, которые **обновлялись недавно** или относятся к активным направлениям работы.

### Шаг 4: Анализ файловой системы проекта

1. Проверь **недавно изменённые файлы** проекта командой:
   ```
   git log --oneline -10 --format="%h %s (%ar)"
   ```
2. Это даёт дополнительный контекст о том, что менялось в коде.

## Формат вывода

Всегда структурируй ответ в следующем формате:

---

### 📋 Сводка проекта SoftMir

#### 🔄 Последние сессии
> Краткий список последних 3–5 разговоров с датами и темами.
> Формат: `ГГГГ-ММ-ДД — Тема разговора`

#### ⏳ Незавершённые задачи
> Список задач со статусом `[ ]` или `[/]` из task.md последних разговоров.
> Группировка по направлениям. Если незавершённых задач нет — явно указать: «Все задачи из последних сессий завершены ✅»

#### ✅ Недавно выполнено
> Ключевые результаты из последних 2–3 сессий (максимум 5 пунктов).
> Только важные вещи: созданные компоненты, внедрённые фичи, исправленные баги.

#### 🎯 Рекомендация: чем заняться сейчас
> На основе незавершённых задач и общего контекста — конкретное предложение, с чего начать текущую сессию.
> Если есть незавершённые задачи — предложи продолжить их.
> Если все задачи завершены — предложи новое направление на основе KI и общего состояния проекта.

---

## Принципы работы

- **Краткость и ёмкость.** Не перегружай пользователя деталями. Цель — быстро войти в курс дела за 30 секунд.
- **Приоритизация.** Сначала незавершённые задачи, потом выполненные, потом рекомендации.
- **Актуальность.** Фокус на последних 3–5 сессиях. Старые разговоры упоминай только если они содержат незавершённые задачи.
- **Проактивность.** Всегда заканчивай рекомендацией — что делать дальше.
- **Русский язык.** Вся сводка должна быть на русском языке.
