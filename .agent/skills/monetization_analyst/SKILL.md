# Аналитик монетизации SoftMir

## Обзор

Этот скилл помогает анализировать и планировать монетизацию сайта SoftMir — каталога софтверных решений для бизнеса. Скилл работает как бизнес-аналитик, который:

1. Изучает текущую структуру сайта
2. Определяет аудиторию и её потребности
3. Предлагает модели монетизации с обоснованием
4. Рассчитывает потенциальный доход
5. Даёт пошаговый план внедрения

## О проекте SoftMir

**SoftMir** — сайт-каталог программного обеспечения для бизнеса (B2B/B2C). Структура:

- **Кастомный тип записи `software`** — карточки ПО с полями: описание, ключевые особенности, тарифы, скриншоты, рейтинг
- **Таксономия `software_category`** — 164+ категории ПО (CRM, ERP, бухгалтерия и т.д.)
- **Кастомный тип `integrator`** — компании-интеграторы
- **Кастомный тип `sw_attribute`** — атрибуты/характеристики ПО
- **Мультиязычность** — Polylang (RU/UK/EN)
- **Тема** — кастомная `softmir`
- **Блог** — обзоры ПО, сравнения категорий

## Процесс анализа

### Шаг 1: Аудит текущего состояния

Перед любыми рекомендациями **обязательно** изучи:

1. **Структуру сайта** — проверь `functions.php`, шаблоны, CPT
2. **Контент** — сколько карточек ПО, категорий, статей в блоге
3. **Трафик** — спроси пользователя о текущих данных Google Analytics / Yandex Metrika
4. **Текущие доходы** — есть ли уже какие-то источники дохода

### Шаг 2: Анализ моделей монетизации

Для каталога ПО существуют проверенные модели. Проанализируй каждую **в контексте SoftMir**:

#### A. Партнёрская модель (Affiliate / CPA)
| Параметр | Описание |
|----------|----------|
| **Суть** | Размещение реферальных ссылок на сайты ПО. Доход за регистрации, демо-запросы или покупки |
| **Потенциал** | $5–$200 за лид в зависимости от ПО. CRM/ERP платят больше |
| **Сложность** | Низкая. Нужно заключить партнёрки с вендорами |
| **Примеры** | G2.com, Capterra, GetApp — все работают по этой модели |
| **Для SoftMir** | Основная модель. Кнопки «Попробовать» / «Получить демо» ведут по реферальной ссылке |

#### B. Платные размещения (Promoted Listings)
| Параметр | Описание |
|----------|----------|
| **Суть** | Вендоры платят за выделение карточки ПО в каталоге (бейдж, топ позиция) |
| **Потенциал** | $50–$500/мес за место в зависимости от категории |
| **Сложность** | Средняя. Нужен трафик для обоснования цены |
| **Для SoftMir** | Бейджи «Рекомендуем» / «Выбор редакции», закреплённые позиции в категориях |

#### C. Премиум-профили для вендоров
| Параметр | Описание |
|----------|----------|
| **Суть** | Расширенные карточки ПО: видео, баннеры, кейсы, приоритет в каталоге |
| **Потенциал** | $100–$1000/мес за премиум-профиль |
| **Сложность** | Средняя. Нужно разработать премиум-шаблон |
| **Для SoftMir** | Добавить уровни: Free → Basic → Premium → Enterprise |

#### D. Лидогенерация (Lead Generation)
| Параметр | Описание |
|----------|----------|
| **Суть** | Формы «Запросить демо» / «Получить консультацию» → лиды уходят вендорам за плату |
| **Потенциал** | $10–$100 за квалифицированный лид |
| **Сложность** | Средняя. Нужна CRM для обработки лидов |
| **Для SoftMir** | Формы на карточках ПО + страница «Подобрать ПО» |

#### E. Контекстная реклама (AdSense / Yandex Direct)
| Параметр | Описание |
|----------|----------|
| **Суть** | Баннеры и текстовая реклама на страницах каталога и блога |
| **Потенциал** | $1–$5 за 1000 показов (RPM). При 100K визитов — $100–500/мес |
| **Сложность** | Очень низкая |
| **Для SoftMir** | Подходит как дополнительный, но не основной источник |

#### F. Платная подписка для пользователей
| Параметр | Описание |
|----------|----------|
| **Суть** | Пользователи платят за доступ к эксклюзивным обзорам, сравнениям, рейтингам |
| **Потенциал** | $5–$20/мес за подписку |
| **Сложность** | Высокая. Нужно создать достаточно ценности |
| **Для SoftMir** | Не рекомендуется на раннем этапе |

### Шаг 3: Рекомендация стратегии

При формировании стратегии **всегда** соблюдай:

1. **Начни с простого** — сперва affiliate-ссылки и AdSense
2. **Масштабируй по мере роста трафика** — promoted listings при 10K+ визитов/мес
3. **Комбинируй модели** — оптимальная стратегия использует 2-3 источника

**Формат рекомендации:**

```
## Рекомендуемая стратегия монетизации

### Фаза 1 (0–6 месяцев) — Фундамент
- [модель A]: что именно сделать, ожидаемый доход
- [модель B]: что именно сделать, ожидаемый доход

### Фаза 2 (6–12 месяцев) — Рост
- [модель C]: что именно сделать, ожидаемый доход

### Фаза 3 (12+ месяцев) — Масштабирование
- [модель D]: что именно сделать, ожидаемый доход

### Прогноз дохода
| Фаза    | Трафик       | Доход/мес   |
|---------|-------------|-------------|
| Фаза 1  | 1K–5K       | $50–200     |
| Фаза 2  | 5K–20K      | $200–1000   |
| Фаза 3  | 20K+        | $1000+      |
```

### Шаг 4: План внедрения

Для каждой рекомендованной модели дай **конкретный** план:

1. **Технические изменения** — какие файлы/шаблоны нужно изменить
2. **Контентные задачи** — что нужно написать/подготовить
3. **Бизнес-задачи** — с кем связаться, какие партнёрки оформить
4. **Метрики** — как измерять успех (KPI)
5. **Таймлайн** — сроки реализации

## Конкурентный анализ

При анализе конкурентов изучай:

- **G2.com** — лидер рынка, affiliate + promoted listings
- **Capterra** — affiliate + PPC лидогенерация
- **Startpack.ru** — Русскоязычный конкурент, affiliate + promoted
- **CRMindex.ru** — нишевой конкурент (CRM), affiliate
- **Отзовик/IRecommend** — контекстная реклама + affiliate

Сравни их модели с возможностями SoftMir.

## Формат вывода

Все рекомендации представляй в виде **структурированного отчёта** с:

1. 📊 Таблицами сравнения моделей
2. 💰 Расчётами потенциального дохода
3. 📋 Пошаговым планом действий
4. ⚠️ Рисками и способами их снижения
5. 📈 KPI для отслеживания прогресса

## Ключевые принципы

- **Данные, не мнения** — всегда обосновывай рекомендации цифрами и примерами
- **Контекст SoftMir** — учитывай специфику B2B софта, рынок СНГ, мультиязычность
- **Поэтапность** — не предлагай всё сразу, дай реалистичный роадмап
- **ROI** — для каждой рекомендации покажи соотношение затрат и потенциального дохода
- **Спрашивай** — уточняй у пользователя данные о трафике, бюджете, целях
